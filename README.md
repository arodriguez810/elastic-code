# Elastic Code — descargas

Aquí solo están las **versiones compiladas** de Elastic Code (el IDE con Claude Code de Flowless). El código vive en el repositorio de Flowless.

Descarga la última versión en **[Releases](https://github.com/arodriguez810/elastic-code/releases/latest)**:

| Sistema | Archivo |
|---|---|
| macOS (Apple Silicon) | `Elastic-Code-macos-arm64.zip` — descomprime y abre «Elastic Code.app» |
| macOS (Intel) | `Elastic-Code-macos-amd64.zip` |
| Windows | `elastic-code-windows-amd64.exe` |
| Linux / WSL (x64) | `elastic-code-linux-amd64` |
| Linux (ARM) | `elastic-code-linux-arm64` |

Un solo ejecutable, sin instalar nada. Elastic Code avisa solo cuando hay una versión nueva y se actualiza desde aquí. `SHA256SUMS.txt` trae la huella de cada archivo.

En macOS, la primera vez: clic derecho → **Abrir** (la app no está firmada por Apple).
